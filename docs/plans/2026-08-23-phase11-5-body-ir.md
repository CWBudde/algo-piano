# Phase 11.5 body-IR attribution

## Question and method

The Phase 11.5 audit separates two explanations for an apparently better piano
render:

1. the body IR contributes useful spectral coloration; or
2. the body IR mostly compensates for an absolute-level mismatch that the
   RMS-normalizing objective cannot see.

`cmd/body-ir-audit` renders the same fixed-length, unclipped floating-point C4
twice. The control uses the identity body `[1]`; the treatment uses exactly one
of a WAV, the current analytical default, or a `body-modal-transfer-v1`
artifact. Both renders use identical preset, velocity, release, and duration.
The room stage is disabled and the first-class body path is held at unity gain,
so only the selected body response differs.

The report records:

- body-IR peak, DC gain, L2 gain, and 0-500 Hz / 500 Hz-2 kHz / 2 kHz-Nyquist
  transfer levels;
- fixed-gain render peak, RMS, reference RMS gap, and attack/sustain/decay
  spectral gaps;
- the existing analysis score and raw overall/low/mid/high spectral errors
  after explicit RMS matching; and
- selected-minus-identity deltas plus a deterministic attribution.

A fixed-level improvement that disappears after RMS matching is classified as
`level_compensation`. An equal-RMS spectral improvement is
`coloration_contribution`. A material level change combined with an equal-RMS
spectral regression is `level_effect_with_coloration_regression`. The report
can also say `neutral` or `coloration_regression`. The composite score remains
in the report, but cannot mask a regression in the spectral metric this audit
is intended to isolate.

The implementation is fenced by three controls: identity produces zero deltas,
a scalar impulse is level compensation, and a low-pass fixture matched by the
reference remains a coloration contribution after RMS matching. Invalid or
non-finite inputs fail rather than producing a plausible-looking report.

## Reproduction

The pinned C4 command is:

```sh
just audit-body-ir
```

It uses `assets/presets/fitted-c4-mayfly.json`, MIDI 60, velocity 118, a
3.5-second release, 48 kHz, and a five-second fixed render. It writes
`out/body-ir-audit.json`. A fresh clone skips cleanly because
`reference/c4.wav` is deliberately gitignored.

Other body sources can be audited directly:

```sh
go run ./cmd/body-ir-audit --reference reference/c4.wav --preset assets/presets/fitted-c4-mayfly.json --body-wav path/to/body.wav --format json
go run ./cmd/body-ir-audit --reference reference/c4.wav --preset assets/presets/fitted-c4-mayfly.json --body-transfer path/to/transfer.json --format table
go run ./cmd/body-ir-audit --reference reference/c4.wav --preset assets/presets/fitted-c4-mayfly.json --analytical-default --format json
```

Supplying zero or multiple body-source flags is an error. A reference shorter
than the requested fixed duration is also an error; choose a duration the
recording actually covers rather than silently padding it.

## Current evidence and decision

Running the pinned command on 2026-08-23 with the local C4 reference showed
that the analytical seed raised candidate RMS by **26.77 dB**. After explicit
RMS matching, overall spectral error worsened by **5.93 dB**: the low band
improved by **0.36 dB**, while the mid and high bands worsened by **1.01 dB**
and **5.38 dB**, respectively. The composite score improved by only 0.00285,
which does not override the direct spectral result. The report classifies this
as `level_effect_with_coloration_regression`.

The present evidence therefore says the analytical seed has a very large level
effect and harmful coloration after level matching. It must not become the
Phase 17 default unchanged. A structural modal artifact should be audited
through the same identity/equal-RMS controls before any production selection.
